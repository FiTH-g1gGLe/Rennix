# Security

If you find a security problem in Rennix, please **don't** open a public issue. Instead, report it privately using GitHub's [**Report a vulnerability**](https://github.com/FiTH-g1gGLe/Rennix/security/advisories/new) button on the Security tab.

Please include what you found, how to reproduce it, and which version you were using. You'll get a reply as soon as possible.

## What Rennix does with your data

- Rennix only contacts TheMovieDB (to look up titles and download artwork) and GitHub (to check for updates).
- Nothing about you or your files is collected or sent anywhere else.
- Diagnostic reports hide your TheMovieDB key, and are only shared if you paste them somewhere yourself.

Only the latest release receives security fixes.
